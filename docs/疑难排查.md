# 疑难排查手册

面向"老师报告了问题，但描述不清"的场景。**先要日志，再猜原因。**

## 一、日志拿取方式

程序里：**设置 → 打开日志目录**（`D:\IdiotLaunch\data`）。

| 文件 | 看什么 |
|------|--------|
| `daemon.log` | 更新检查/下载/安装、快捷方式重建、清理、早读时间段刷新、异常堆栈汇总 |
| `ui.log` | 前端启动流程、子窗口创建、单实例判定、界面操作报错 |
| `backend.log` | HTTP 服务启停、托盘/悬浮球线程异常 |
| `morning.log` | 早晚读浏览器（页面加载失败、自动登录注入） |
| `countdown.log` | 壁纸/屏保播放器 |
| `telemetry.log` | 已经/准备上报的匿名事件（网络不通时也能看到） |
| `state.json` | 当前更新状态、pending 安装包、daemon 状态 |

日志会轮转（`daemon.log` 最多 4 份 × 256KB），不用担心里面被覆盖掉关键信息。

## 二、按现象排查

### 1）双击图标没反应 / 窗口不出来

1. 先看任务管理器有没有 `IdiotLaunch.exe`。有 = 程序已经在跑（可能在托盘里），
   再双击一次会把窗口调出来（走 `/api/activate`）。
2. 有进程但窗口不出来：右键托盘图标 → 打开主界面。如果托盘图标也没有，
   说明后端没起来 → 看 `backend.log` / `daemon.log`。
3. 都没有 → 看 `ui.log`：常见是 `D:\IdiotLaunch\data` 不可写（D 盘满/只读/被占用）。

### 2）界面能打开，但功能都失败（"后台服务未运行"横幅）

- 点横幅上的「重试」。
- 仍不行：确认 `D:\IdiotLaunch\backend\IdiotLaunchBackend.exe` 存在（可能被杀软删了）。
- **杀软/安全软件**：ARIA2C、PyInstaller 打包的 exe 容易被误报。需要把安装目录加入白名单，
  否则会表现为"下载更新永远失败""后端起不来"。
- 防火墙一般不影响（只监听 127.0.0.1）。

### 3）更新相关

| 现象 | 原因 | 处理 |
|------|------|------|
| 横幅一直"最新版本"但明明有新版本 | 教室网络访问不了 Supabase/GitHub | 看 `daemon.log` 里"更新检查完成"那一行；确认能访问外网 |
| 一直"正在下载"然后失败 | 镜像源都不通，或 aria2c 被杀软拦 | `daemon.log` 里有每轮失败记录；把 `assets\aria2c.exe` 加白名单 |
| 点了「一键更新」后程序没回来 | 安装包被 SmartScreen/安全软件拦下，或安装被取消 | 手动去 `D:\IdiotLaunch\data` 看有没有 `IdiotLaunch_Setup_*.exe`，双击手动装 |
| 更新后版本号没变 | 安装没真正执行（被拦截），或 tag 与 `LAUNCHER_VERSION` 不一致 | 后者只在开发时出现，CI 会拦；前者看系统事件/安全软件 |
| `data` 目录越来越大 | 更新包残留 | daemon 每小时清理一次；也可手动删 `IdiotLaunch_Setup_*.exe*`（不要删 `state.json`） |

### 4）壁纸/倒计时

- **壁纸不出现**：`countdown.log` 看播放器是否启动；壁纸页面来自 `zztool.free.nf`，
  断网会显示错误页或黑屏。
- **关闭壁纸后桌面不正常**：桌面被 `SPI_SETDESKWALLPAPER` 重设成当前那张静态图，
  右键桌面 → 个性化 → 重新选壁纸即可。若桌面是纯色/幻灯片，见 HANDOFF 的已知取舍。
- **任务栏没了 / 鼠标指针不见了**：屏保进程被强杀（例如更新、断电）导致没来得及恢复。
  注销或重启资源管理器（任务管理器 → 重启 `explorer.exe`）即可恢复。
- **本地视频壁纸黑屏**：`countdown.log` 看本地 HTTP 服务是否报错；视频过大或编码特殊
  （如 HEVC）时 Chromium 解不了。

### 5）早晚读

- **页面打不开**：窗口会显示中文提示页，说明网络/站点问题；点「刷新」重试。
- **不自动进班级**：`morning.log` 里看是否注入脚本失败；网站改版会导致选择器失效。
- **登录提示"无法连接早读服务器"**：这是网络问题，不是密码问题（两者提示已分开）。
- **登录后还是显示未登录**：`morning_config.json` 是否写入成功；D 盘是否可写。
- **悬浮球不出现**：只在早读/晚读时间段显示（时间段来自服务器，`daemon.log` 每 10 分钟刷新一次）；
  右键悬浮球可以隐藏，下次启动恢复。

### 6）关不掉程序

- 窗口 ✕ = 收进托盘（第一次会提示）。
- 托盘右键 → **退出（结束后台）**，会一并关掉壁纸和早晚读窗口。
- 程序内：设置 → 彻底退出程序。
- 都不行时：任务管理器结束 `IdiotLaunch.exe` 和 `IdiotLaunchBackend.exe`（两个都要）。
  如果桌面壁纸没恢复，手动重设一次壁纸。

### 7）"未响应"（界面卡住）

历史上是倒计时/秒表子窗口的 Win32 调用互相等待导致的，已改为非阻塞调用
（见 HANDOFF 第二节）。如果新版本仍然出现：

- 看 `ui.log` 里最后一次操作和是否有异常；
- 记录是"打开第几个窗口""点了哪个按钮"之后卡住的，这是定位关键。

## 三、给 IT 管理员的信息

- 安装位置固定 `D:\IdiotLaunch`；数据在 `D:\IdiotLaunch\data`；写注册表只有两项：
  安装信息（HKCU Uninstall，`PrivilegesRequired=lowest`）和可选的壁纸开机自启
  （`HKCU\...\Run\CountdownDesktop`，可在设置里关）。
- 程序**不需要管理员权限**，不安装驱动、不改系统设置（除了恢复桌面壁纸这一项）。
- 网络需求：`zztool.free.nf`（早晚读/倒计时页面与 API）、`api.github.com` /
  `github.com` / 若干 `ghproxy` 镜像（更新）、Supabase（版本信息与匿名统计，
  可在设置里关闭统计）。
- 想彻底禁用自动更新：设置 → 自动更新 → 关。程序仍会每小时检查一次版本（只查询，不下载）。
